Skill-Gap Agent

Setup — your AI access

One-time setup: an API key unlocks LLM skill extraction and analysis. The key goes straight to the local agent, which keeps it in the OS credential vault (Windows Credential Manager / macOS Keychain) — never in the browser.

Uncheck "remember" to keep the key for this server session only.

Where your data goes: analysis sends your resume and job-description text to this provider over HTTPS (OpenRouter forwards to the underlying model — default DeepSeek; Z.ai GLM; OpenAI) — some processing outside your country. GitHub Search receives skill-gap terms only. Nothing goes to the extension's developer.

Setup — analysis mode

How your resume and job descriptions are processed. Applies to skill extraction here and to gap analysis later.

Free models cost nothing, but the providers behind them may log or use your inputs for training. Job descriptions are public — your resume is not: it contains personal information (name, contact details, work history) and will be sent to these third-party providers. Your own key's paid endpoints generally do not train on inputs. Consent is required before any free-mode run.

The file stays on this machine under output/uploads/; the extracted text is sent over HTTPS to the AI provider selected above for skill analysis (unless Rule-based mode is selected — extraction is local and nothing leaves the machine) — never to the extension's developer.

Setup — your resume

Upload the resume to analyze against (PDF, DOCX or TXT). The file is kept locally under output/uploads/; the extracted text is sent over HTTPS to the AI provider selected above (OpenRouter → DeepSeek, Z.ai GLM or OpenAI — some processing outside your country) for skill extraction and analysis. Extraction follows the mode selected above: Rule-based mode extracts locally and nothing leaves the machine. It is never sent to the extension's developer. GitHub Search receives skill-gap terms only, never resume text.
