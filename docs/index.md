# Skill-Gap Agent

A Chrome extension that captures the job descriptions you are viewing and
generates a ranked skill-gap analysis and practice plan — with a local
companion program on your own computer.

**Privacy:** this product's data handling is described in the
[Privacy Policy](privacy-policy.md). In short — everything runs locally;
the only data that leaves your computer goes to the AI provider you choose
and to GitHub's public search API; the developer receives nothing.

Our use of user data complies with the Chrome Web Store User Data Policy,
including the Limited Use requirements:

> The use of information received from Chrome APIs will adhere to the
> Chrome Web Store User Data Policy, including the Limited Use
> requirements.

Not affiliated with, endorsed by, or sponsored by LinkedIn Corporation.
Analysis results are generated by AI and are advisory.
