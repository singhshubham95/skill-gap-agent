   `m13_check` stays green.

   what is collected (resume file + text, JD text, skills, API keys), the

   policy changes, contact; and carries the Chrome Web Store **Limited
   Use** affirmative statement verbatim.

   links the policy and carries the Limited Use statement.

   AI-generated-content notice); reviewer test instructions; a pre-submit
   checklist (Pages enable, trademark search, dashboard paste order).

   license.
6. `m22_check.py` + `test_m22.py` green (icon/manifest validity, policy
